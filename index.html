EstadoArchivoOrigenFechaProveedorValorObservación
Regla de seguridad: los registros con errores no se importan. Los duplicados exactos se omiten automáticamente. Si el mismo proveedor + documento/referencia aparece con datos diferentes, se marca como conflicto y tampoco se importa automáticamente. Las advertencias, como una fecha fuera del mes nominal del archivo, se conservan para revisión.
